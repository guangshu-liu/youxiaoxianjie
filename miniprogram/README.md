# 微信小程序版

同一套题库、同一套组局逻辑，界面用 WXML 重写，奖励从「转盘抽奖 + 积分兑现金」
改成**确定性的星星与徽章**。

## 为什么改掉了转盘

微信《常见拒绝情形》3.2.8.9 把「有奖竞猜和抽奖」列为违规，积分兑换现金也属于
高危项。即使只做体验版不过审，这套机制也不值得留着 —— 而这个游戏真正的动力
本来就不是赌运气。

现在的规则：**选一科，一局 10 题**（三科各 200 道题）。答对 **9–10 题 3 星**、
**6–8 题 2 星**、**0–5 题 1 星**。阈值按科目分开配置，以后要单独调数学不用改逻辑。
星星累计到 **10 / 30 / 50 / 100** 各解锁一个徽章（🍟 薯条 / 🤖 布鲁克 / 📺 动画片 / 🛒 超市）。

## 前置

### 1. 安装开发者工具

[下载地址](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
Mac 上也可以 `brew install --cask wechatwebdevtools`。

### 2. 注册小程序，拿 AppID

只有注册后才能**真机预览**和**上传体验版**；游客模式只能在电脑模拟器里跑。
注册免费，个人主体即可，需要身份证 + 银行卡实名。

1. 打开 <https://mp.weixin.qq.com/> → **立即注册** → 选 **小程序**（不要选订阅号/服务号）。
2. 用一个**没在微信公众平台注册过**的邮箱，填密码，去邮箱点激活链接。
3. 主体类型选 **个人**，填身份证姓名/号码、管理员手机号，短信验证。
4. 登录后台 → **开发管理 → 开发设置**，复制 **AppID**（`wx` 开头 16 位）。

> 体验版**不需要**：微信认证（约 30 元）、ICP 备案、类目审核、代码审核。
> 这些都只卡「正式发布」。但备案周期 1–4 周且不支持加急，只要打算上线，
> 就在做体验版的同时把备案提了 —— 见「正式上线：备案 → 提交审核 → 发布」。

### 3. 把 AppID 写进项目

```bash
npm run mp:appid -- wx1234567890abcdef   # 会先校验格式再写盘
npm run mp:appid -- --check              # 随时复核当前用的是不是正式号
```

> **只需要 AppID，不需要 AppSecret。** 密钥是服务端凭据，只在调用
> `code2Session` / 获取 access_token 这类接口时用；本项目没有服务端，
> 上传代码靠的是开发者工具里登录的微信账号。
> **绝对不要把 AppSecret 写进仓库或前端代码** —— 拿到它就能以你的
> 小程序身份调用服务端接口。

### 4. 题干朗读：不需要任何后台配置

孩子认字少，题目靠读出来。最初试过微信官方的**同声传译**插件
（`wx069ba97219f66d99`），但那个插件**只对企业主体小程序开放**，本项目是
个人主体，后台添加后上传仍报 `80082 get plugin ... permission deny`；更糟的是
只要 `app.json` 声明了插件，未授权时**整个小程序启动失败**，不是「没声音」
而是页面打不开。所以这套方案已经换掉。

1.2.6 又踩了一个坑：音频放 `pkgTts` 分包、播放器留在主包，而微信规定
「主包不能直接引用分包资源」，真机上 `InnerAudioContext` 拿不到分包路径 ——
**读题喇叭在，但一点声音都没有**；叠加 `wx.loadSubpackage` 回调不落地时
请求会永远排队。1.2.7 起改成**预生成音频直接放主包**：

`tools/gen_tts_audio.py` 按题库规则把 171 条中文题干念成 m4a（0.97 MB），
放进主包 `ttsAudio/`，`lib/tts.js` 按文本查 `tts-map.js` 直接播放。
**不需要插件、不需要分包、不需要联网、不需要域名白名单、不需要在后台点任何东西。**

> 体积怎么压下来的：`afconvert` 会给每个 m4a 塞约 3 KB 的 `free` 页对齐
> 填充块，171 个文件白占 515 KB。生成器剥掉它并修正 `moov/stco` 偏移表，
> 解码出的 PCM 逐字节不变（音质、时长、音量都不动），主包合计约 1.81 MB。
> 改动题库或朗读规则后跑 `npm run tts:audio` 重新生成，否则
> `npm run verify` 会挡住「清单与规则不一致」。

## 构建

小程序用的题库、逻辑、音频都是**生成的**，不在 git 里：

```bash
npm run mp:build     # 生成 miniprogram/generated/
```

生成内容：

| 产物 | 来源 |
|---|---|
| `generated/lib/game.js` | `src/js` 的 00-core / 10-store / 30-bank / 40-runner 拼接 + 垫片 |
| `generated/data/bank.js` | `src/data/*.json` + 配比 |
| `generated/data/audio.js` | `tools/audio_manifest.json` |
| `generated/audio/en/*.m4a` | `audio/en/` |

**逻辑只有一份**：网页版改了 `src/js` 里的纯逻辑，重新构建小程序就跟着变，
不存在两套实现各自漂移。

## 运行

> **导入前先跑一次 `npm run mp:build`。** `miniprogram/generated/` 被 `.gitignore`
> 排除，仓库里只有源码；新机器 `git clone` 后没有 `game.js` / `bank.js` / 音频映射
> 和 40 个 `.m4a`，直接导入会白屏。原始语音 `audio/en/*.m4a` 已在仓库里，
> 不需要重新生成。跑 `python3 tools/build_miniprogram.py --check` 可复核产物是否齐全。

1. 微信开发者工具 → **导入项目** → 目录选 **本文件夹**（`miniprogram/`）。
2. AppID 会自动从 `project.config.json` 读取（就是上一步写入的那个）。
3. 编译，模拟器里就能玩。

> 想用命令行（`cli open` / `preview` / `upload`）控制工具，额外还有两个前提：
> 已用微信扫码登录，且 **工具 → 设置 → 安全设置 → 开启「服务端口」**。
> 没开端口时 CLI 一律报 `IDE service port disabled`，`--port` 参数也绕不过去。
> 可执行文件：`/Applications/wechatwebdevtools.app/Contents/MacOS/cli`。

## 发体验版给家人

1. 开发者工具右上角点 **上传**，填版本号（如 `1.2.6`）和备注。
   - 「上传」按钮不出现，通常是 AppID 还是 `touristappid`，跑 `npm run mp:appid -- --check` 确认。
2. 打开 <https://mp.weixin.qq.com/> → **管理 → 版本管理**。
3. 找到刚上传的开发版本 → **选为体验版**。
4. **管理 → 成员管理 → 体验成员**，把家人的微信号加进去（上限 90 人）。
5. 在版本管理页下载 **体验版二维码**，发给家人扫码。

**体验版不需要提交审核**，所以不会触发类目和抽奖相关的审核问题。
体验成员之外的人扫这个码打不开——这是预期行为。

只给家人内测的话，到这里就可以收工。要正式上架，往下看
「正式上线：备案 → 提交审核 → 发布」——**备案现在就该并行提交**。

- [ ] **三种听音题（听音选字母 / 听音选词 / 辨短元音）进题就自动播一遍**（第 1 题和第 5 题都试）

## 正式上线：备案 → 提交审核 → 发布

> **2023-09-01 起，境内主体、尚未上架的小程序必须先完成 ICP 备案才能上架。**
> 备案卡的是「提交代码审核 → 发布」，**不卡开发版和体验版**：家人扫码内测不用等。
> 但备案动辄几周且不支持加急，别等真机验收做完才想起来 —— 上传体验版的
> 同时就去提备案，两条线并行。境外主体暂不需要备案。

### 备案流程与时长

入口：<https://mp.weixin.qq.com/> → **设置 → 小程序备案 → 去备案**（后台首页
也有「去备案」提示）。不收费；个人主体主要是身份证件 + 负责人人脸核身。

| 环节 | 时效 |
|---|---|
| 微信平台初审 | 1–2 个工作日 |
| 工信部短信核验 | 初审通过后 `12381` 下发短信，**24 小时内**到 <https://beian.miit.gov.cn/> 完成核验，超时自动驳回、需重新提交 |
| 各省通信管理局审核 | 1–20 个工作日（法定上限 20 个工作日，不含周末与节假日） |
| 初审驳回后重新提交 | 再等 7 个工作日，然后重新排队 |

顺利约 1–2 周，**按 3–4 周排期**；材料被打回就是一个月以上。不支持加急，
微信平台也催不动管局。进度在后台备案页看，结果由站内信 / 模板消息 / 短信通知。
五个环节依次是：填写信息 → 平台初审 → 短信核验 → 通管局审核 → 备案成功。

### 这个项目备案要避的坑

- **教育类目别选错。** 官方前置审批清单里有「校外培训 → 教育部门允许开展
  校外培训的审批文件」。本项目是**免费识字答题游戏，无课程、无培训、无收费**，
  服务内容照实选非培训类，别写「学科培训」「幼小衔接课程」之类表述，否则会被
  要求补前置审批文件，直接卡住。`在线识字` / `幼小衔接闯关` 这类名称可能触发
  人工问询，补充说明材料里讲清性质即可。
- **提交后别改小程序信息。** 名称、主体、类目、负责人在备案期间变更，会导致备案
  信息与小程序信息不一致而被驳回；订单进入「管局审核中」后无法撤回，只能等结果。
  备案名称要与微信认证名称一致。
- **保持电话畅通。** 平台核实电话多为 `0755` 开头；主体负责人与小程序负责人
  不要用同一个手机号。人脸核身用白色/浅色纯净背景，不戴帽子、口罩、耳机。
- 备案通过后备案号会**自动**显示在小程序「更多资料」页，不用自己挂。

### 备案通过后

1. **管理 → 版本管理 → 开发版本** → 找到已完成真机验收的版本 → **提交审核**。
2. 按提示填类目、功能页面；本项目无登录、无服务端，测试账号留空并说明即可。
3. 审核通过后管理员微信会收到通知 → **版本管理 → 审核版本 → 发布**
   （普通小程序选全量发布即可）。

提交审核前把上面「上线前的真机验收」清单全部过完，别拿没验过的版本去审。

## 和网页版的差异

| | 网页版 | 小程序 |
|---|---|---|
| 奖励 | 每答对一题转一次盘 | 一局结束按正确率给 1–3 星 |
| 兑换 | 500 分兑 1 元 | 没有（星星只用来解锁徽章） |
| 存档 | localStorage | `wx.setStorageSync`，**两套独立** |
| 备份 | 下载文件 / 剪贴板 | 只走剪贴板 |
| 家长录音覆盖 | 有 | 没有 |
| 语音 | Web Audio + 文件 | `InnerAudioContext` + 包内文件 |
| 题干朗读 | 系统 `speechSynthesis`，零文件、离线可用（首次需手势解锁） | 主包 `ttsAudio/` 内预生成 m4a，离线可用、进题即播 |
| 音效 | 振荡器合成 | 同左，走 `wx.createWebAudioContext()` |

两套存档靠**备份 JSON 互通**：网页版导出的备份可以直接粘进小程序的家长页恢复
（音频录音会丢，其余都在）。

## 已知风险

- `wx.createWebAudioContext()` 需要基础库 **2.19.0+**。拿不到上下文时音效退化
  成震动，游戏本身不受影响。**真机上务必验一遍对错音效**。
- `wx.setInnerAudioOption({ obeyMuteSwitch: false })` 只作用于 **InnerAudioContext**
  （也就是题干语音）。`app.js` 在 `onLaunch` 里、创建任何音频实例之前调用，所以
  iOS 静音开关打开时听音题照常出声。注意实例上的 `obeyMuteSwitch` 属性从基础库
  2.3.0 起已不生效，只能用这个全局接口。
  **它管不到 WebAudioContext**：答对/答错的合成音效在 iOS 静音模式下很可能不响，
  这是平台限制，微信没有给 WebAudioContext 提供对应开关。要让音效在静音下也响，
  只能把 `sfx.js` 改成播放预生成音频文件、同样走 InnerAudioContext。改造前不要把
  「静音下音效要响」当必过项。真机无声时看 vConsole 里 `[audio]` / `[app]` 的日志。
- 题干语音是包内绝对路径（`/generated/audio/en/*.m4a`），不联网、不需要域名白名单。
  第 2 题之后是程序触发的自动播放，某些机型可能不响 —— 喇叭按钮可以手动重播。
- **题干朗读也走 InnerAudioContext**，所以同样受 `obeyMuteSwitch:false` 保护。
  音频是主包内绝对路径（`/ttsAudio/*.m4a`），和英文单词音频同一条链路，
  不联网、不预下载、不需要域名白名单。真机读题没声时先看 vConsole 的
  `[tts] 播放开始 / 播放失败` 日志：前者没打印说明没走到播放层（检查家长
  开关、`tts-map.js` 是否命中），后者带 errMsg 则说明路径或格式有问题。
